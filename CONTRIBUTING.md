# Contributing

This repository preserves a historical Unity animation utility. Keep modernization changes small and distinguish original behavior from new functionality.

Before submitting changes:

1. Contribute code under the MIT License and do not contribute third-party assets without redistribution permission.
2. Describe the problem, expected behavior, actual behavior, Unity version, rig type, and render pipeline.
3. Include a minimal reproduction using assets you may share.
4. Preserve Unity `.meta` files and controller references.
5. Report exactly what you tested in Play Mode and in a build. Do not claim support for versions you have not tested.

Do not commit Library, Temp, Logs, UserSettings, credentials, Asset Store upload tooling, or unrelated project changes.

See [implementation notes](docs/IMPLEMENTATION-NOTES.md) for known areas needing validation.
